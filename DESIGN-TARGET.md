## North star

A referred seller or buyer who lands on sodemanrealty.com should think:

> “This is a real independent brokerage run by a careful local advisor — not a franchise lead funnel.”

The site’s job is **credibility after a recommendation**, not MLS search. Portals find inventory; this site should win the person.

## What the strong independents share

1. **Tiny palette** (2–3 colors)  
2. **One signature move** repeated without exception  
3. **Type doing brand work** (not default Inter/system stacks)  
4. **Things left out** — short nav, few CTAs, no feature stacking  
5. **Place + person** ahead of software features  
6. **Proof that is real** — solds, reviews, or process — never placeholders

## Target feel for Sodeman

**Name:** Midwestern Independent — disciplined, calm, local  
**One-line feel:** Lansing-area brokerage that looks like careful counsel, not a portal clone.

### Brand hierarchy (first viewport)

Must read as one composition:

1. **Sodeman Realty** as hero-level brand signal  
2. One headline (process / trust — keep the disciplined voice)  
3. One supporting sentence (buyers + investors · Mid-Michigan)  
4. One primary CTA (Request consult / Call)  
5. One dominant visual plane (full-bleed place **or** Joel — not a card grid)

No stats strips, no fake listings, no floating badges in the hero.

### Signature move (pick one and apply everywhere)

**Recommended:** **Process ribbon** — a recurring 3-step “Clarify → Search → Close” motif (line/number treatment) that appears on home, about, and contact. That *is* the product.

Runner-up: **Place band** — every major section opens with a thin Mid-Michigan photo strip (skyline / neighborhood / lake country) at consistent crop height.

### Visual system (target)

| Token | Direction |
|-------|-----------|
| Primary | Keep deep navy (`#0B1F3A` family) — already owned |
| Surface | Move off generic cream if needed toward **cooler stone / paper** so we don’t land in the AI cream+terracotta cliché |
| Accent | Use gold sparingly (rules, links, step numbers) — not as large fills |
| Type | Replace Inter: **display serif or distinctive grotesque for brand/headlines** + clean sans for UI/body (expressive, purposeful — not system default) |
| Radius | Tighten — less “soft SaaS card”; more brokerage editorial |
| Motion | 2–3 intentional reveals (hero, process steps, listing proof) — no shimmer skeletons |

### Voice

Keep what already works: *process over pressure, transparent tradeoffs, conservative execution.*  
Add what Sensibl/Capsule do well: **independence named out loud** (“independent brokerage,” “you work with Joel”), place names that feel specific (Lansing, East Lansing, Delta, Laingsburg, etc. when we have confirmation).
